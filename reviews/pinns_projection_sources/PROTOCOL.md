# 原视频、鸟瞰视频与标注坐标之间的独立对应

既有同一行像素/地面标注分析发现三个美国片的 10 Hz 行人记录存在约一米差异。探索性地用别片行人坐标拟合单应后，在留片时中位差可降至约 0.1 m。该拟合没有独立的物理地标。现用三个异常片和与白昼异常片共用同一份标定的白昼 1 号正常片，直接检查发布的原视频与鸟瞰视频的图像对应。图像对应步骤读取视频和四对标定点，不使用行人轨迹、预测、未来标签或拟合得到的地面坐标。统计针对固定机位这四段已知视频。

用标定 JSON 给出的四角和鸟瞰视频尺寸将原图透视变换到鸟瞰像素平面。以每段的第 0 帧作配准，第 60 帧和第 150 帧检查相同变换。分别从变换后原图与同号鸟瞰图提取 SIFT 特征，L2 最近邻、两侧 0.75 比例和双向一致匹配，记录用发布映射时的像素偏移。第 0 帧以 3 像素 RANSAC 拟合同一对视图间的单应，记录其支持量；如第 0 帧不足 12 个内点，不对该段拟合结果作解释。将同一修正用于后两帧，报告不按几何残差裁剪的原匹配数、逐帧中位和 90 分位；重复背景的帧不能算独立地点。像素到米的转换只依标定范围，可在同一行图像点上检查此次图像配准能解释多少已知像素/地面列差。鸟瞰视频是作者生成的另一个图像产品，不具备独立测绘地面真值。
