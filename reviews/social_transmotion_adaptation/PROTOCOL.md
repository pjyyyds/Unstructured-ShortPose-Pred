# 同一 PINNS 四地的作者代码单路径对照

本方案在该适配模型的任何真实拟合与评分之前固定。已有其他模型的四地结果参与了研究问题的选择。

**主要量**为“轨迹加二维框的作者代码适配版”减“末两点匀速”的单路径 ADE（米），先在各留出地点对窗口平均，再对四地等权。负值表示模型误差更小。同期固定两项次要对照，即“只用轨迹”减匀速，以及“轨迹加框”减“只用轨迹”。所有对照同时保留 3.0 s FDE、逐地差与四地平均差，并以每地点内整片录像配对重采样 20,000 次形成 95% 百分位区间（PCG64，seed 2026）。区间条件为这四地和一个训练种子。所有方向和结果均报告。

**模型和信息条件。** 采用 Saadatnejad 等人 ICLR 2024 作者 JRDB 双层 Transformer 源码，严格固定提交 7695ba335f7cba7f41660d0edc66a57cd52da08a。六层局部、三层全局、128 隐藏宽度、四个注意力头，单人单路径输出。时间维从 9+12（2.5 Hz）改为 5+30（10 Hz）。每窗仅目标行人 5 个实际地面坐标；加框条件另给相同五帧左上角横纵坐标与宽高，按作者代码相对末帧并乘 0.25。纯轨迹条件时，保留同一网络和 token 数，训练与推理时把框数值全部置零。两个条件均无邻人、关节、图像或未来信息。二维框源自已核验的 PINNS 标签，输入可得性取决于实际系统的检测和跟踪。纯匀速直接用末两点的实际 0.1 s 间隔预测后续真实 30 个时刻。

**样本和拟合。** 1,482 个完整 35 点窗口来自 47 片录像。四个地点的测试分母为美国 816、意大利 84、日本 432、泰国 150；每次仅用另三个地点训练。采用 seed 42 从头初始化；两个条件对每折用逐位相同的初始态、打乱顺序和随机数流，保存初始权重哈希。采用作者实际损失（主行人每步二维欧氏误差取均值，乘 100），Adam、批量 16、初始学习率 1e−4、梯度范数截到 1.0。共 28 轮，采用作者式 80% 进度后降十倍（24–28 轮为 1e−5）。只取末轮，未加旋转增强。作者 JRDB 原版使用 seed 0、100 轮并保存验证最佳和最终权重，支持多人场景。此次为面向同一 PINNS 队列的单人短窗适配，未训练或评估原作者数据。没有自称原版权重成绩，也没有将其确定性误差当作六模式 oracle 或概率校准成绩。

**计算与返回。** 每个地点、条件共 8 次拟合，合计 15,680 个优化更新。真实输入预检通过全部 7,410 个历史框。合成输入测试核实两条件的共同初值、作者损失与独立单路径 ADE 的一致性，以及 CPU 暂停/读取后恢复到相同权重。单个 16 窗合成批在本机 4 线程 ARM CPU 上预热后的五次前向、反向及优化中位 0.231 s，对应本机约 1.00 h 的优化时间，不含存盘和评测。Kaggle 设备耗时尚未实测。首选一张 GPU；也可在启动时选择一个 CPU 作业。八次拟合必须固定同一工作节点和设备。每轮保存可恢复状态，各折用终轮 CPU 权重计算持出预测。

**执行方式。** Kaggle 单元 kaggle_cell.py 标签 DEVICE 默认 CUDA，可在投运前固定为 CPU。它校验官方代码、许可证、官方 PINNS 元数据与已接入的 COCO 框缓存。作者的 305 MB 数据/权重包无需下载。生成 /kaggle/working/social_transmotion_pinns/social_transmotion_pinns.zip，内含 8 份权重、源代码身份、真实曲线/逐窗误差、初值证明、按地点及总体的公开聚合。对应源码与修改标注见 THIRD_PARTY.md，公共使用时应一并保留。要手工核验，给项目配置 PYTHONPATH 后运行下面的命令。真实训练仅开放给 Kaggle 入口。

    python run_pinns.py DATA_ROOT POSE.npz UPSTREAM_DIR candidate_plan.json --mode check
    python test_run.py
