# 首标注且小位移行人的五帧预测

将同一批已保存的单人 Social-Transmotion 预测，按此前用五帧历史确定的四组窗口分别评分。四组在这次返包前就已固定，作者模型上的分组比较属于二次分析。[分组定义与冻结人数](../../pinns_short_displacement/PROTOCOL.md) · [作者模型的整体比较协议](../PROTOCOL.md)

最接近开题短历史条件的一组有 323 个窗口，分布在四地 46 段录像中。每窗从行人在片内的第一次采样标注开始，五帧累计地面路长严格小于 0.5 m。末两点匀速、仅轨迹、轨迹加框的四地等权 ADE 分别为 0.3545、0.4514、0.5107 m，三秒 FDE 为 0.8491、0.9671、1.0807 m。加入二维框相对仅用轨迹的 ADE 差为 +0.0593 m，条件 95% 区间为 +0.0248 至 +0.1030 m。该模型的视觉输入是行人框。首次出现标注的原因可能包括跟踪开始或记录开始，尚无独立可见性标注确定何时解除遮挡。

程序从历史缓存重建四组，逐组检查窗键摘要，然后将返包中的单路径与原三秒地面位置配对，重算全部 1,482 个窗口的 ADE 和 FDE。每组的匀速结果另与既有研究交叉核对。每地按整片录像有放回抽样，保留被抽中片段的全部组内窗口，再将四地等权平均。20,000 次重复、PCG64 种子 2026。区间固定了受试地点和模型种子 42，未经多重比较校正。[四组的样本量、地点结果和区间](aggregate.json)

在仓库根目录运行以下命令，提供冻结的历史缓存和原版 Kaggle 返回包。脚本离线读取已存预测并输出汇总。

```bash
python -m reviews.social_transmotion_adaptation.first_short.summarize \
  pinns_matched_histories.npz social_transmotion_pinns.zip aggregate.json
```
