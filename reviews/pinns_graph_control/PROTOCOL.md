# PINNS 四地五帧异类邻居对照

本方案在任何新拟合或模型评分前冻结。V2 的原497窗有 M1 与 M2b 五种子结果。现有1482窗实验比较最近人/车输入的单轨迹岭回归，用片段五折。本方案在同一台 CPU 上比较四个留地点外折，每臂每折 seed 42，共12次拟合。

所有臂使用冻结的1482个窗、47片和原 RTMPose 缓存；每人五个实测轨迹位置、首末间隔0.4秒，未来30个完整位置至3秒。用于入组的未来仅属于预测目标本人。邻居在 t0 的官方跟踪标注中选，不要求任何未来存在，身份为（片段、来源类别、ID）。仅用 t0−4 至 t0 五帧。按10米内非重合距离取最近12个，输入原图网络的九项有向边特征、8维类型及有效掩码。速度由当前与最近一个有效历史位置除以实际时间差，间隔1至4步；速度缺失保留邻体，速度和径向通道置零并置无效掩码。人、车来自原始标注，位置和身份属于标注供给。行人类型据历史有效水平速度小于0.20 m/s映入静止类，缺速度映入通用行人槽；不读取邻居的标注固定状态。车辆映入车型槽6，资料不含自行车或其他命名类别。邻居关节不作为输入。原姿态、运动与目标自身类型字段在全部臂共用，目标类型沿用原标注/历史速度规则。地图和动作监督关闭。

三臂为原 M1，原 M2b 输入真实邻居，原 M2b 在训练和测试均输入形状完全相同的全空图。原 M2b 即便聚合门为零，其末端仍有一层可训练归一化，空图训练是图内容对照。三个模型复制 M1 所有同名形状相同的初始状态，两个 M2b 的图专属初始参数也完全相同。所有臂共享准入、随机样本顺序、批次、五帧姿态、未来标签、网络主干、6模式损失、28轮 AdamW/余弦学习率及梯度裁剪。每个训练批设相同的前半模型随机种子，进入共同解码器时另设相同种子，防止图专属 dropout 改变解码器随机流。原训练完成的 M1 GPU 结果只作历史参照。记录每折软件、CPU、种子、初态摘要、最终权重、窗键、标签、图特征和逐窗六路径、概率、最高概率 ADE/FDE。

主比较为真实 M2b 减 M1 的四地点等权 ADE；辅助比较为真实 M2b 减空图 M2b，以及空图 M2b 减 M1。对已训练的真实 M2b 另作三个推理干预：关闭所有边、去掉车辆边、去掉行人边；仅屏蔽已有槽，不补选第13邻居。边在空掩码下无消息，测试不能把同一冻结网络的失活诊断当重新训练。报告各地、无邻/有人/有车/混合支持、整体与各地误差。使用成对站内整片有放回抽样20,000次（seed 2026），片内所有窗加权，然后四地等权；取边际95%百分位区间。条件为这次训练和已研究的四地点，不识别邻居行为的因果影响。该输入依据官方跟踪标注，不等同实时检测。仅在Kaggle CPU训练，本机进行输入、结构和合成测试。
