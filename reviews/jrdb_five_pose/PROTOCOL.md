# JRDB 五份实际来源骨架对两点运动的增量

本方案在未运行或查看本项新预测前登记。三个室外训练片已用于双姿态和运动开发。沿用9份经 SHA 核验的 ST 训练轨迹、HST 三维骨架与轮式里程计；均由研究作者公开发布。这次观察范围先验审查查到197窗，并已知此前138窗不同取样设计的结果。

固定目标人最后一帧 t0 在 ST 格点上。运动历史为 t0−6 与 t0 的两条有效水平地面记录，未来为同人 t0+6,+12,…,+42 共七个真实发布坐标，对应名义 0.4 至 2.8 秒。HST 的五个来源帧取 t0−6、−5、−3、−2、0，时间间隔依次为1/15、2/15、1/15、2/15秒。仅按原始整数帧号关联，不将帧号当实测纳秒，不插补位置或关节。每窗这五帧与七个目标帧均有里程计帧名；五个时刻的 HST 人 ID 均与 ST 相同，其33个关节三个坐标都需有限。对全部符合条件的起点，按片、片内行人、t0 升序贪心，仅在新历史首帧晚于上个选中窗的最终目标帧时入组。全臂使用相同的197窗，Hewlett-Packard Intersection、Huang Lane、Tressider 分别123、68、6。另在此筛选前报告相同两地面历史和完整未来的候选中，末帧姿态缺失、末帧存在但关节不全、末帧完整但五帧不全、以及全部完整的数量。末帧缺失者不列入这项完整测量条件下的四臂效应；最终样本报告相关缺失分母。

以地面末两点固定匀速预测为共同参考。四个学习臂均按既有双姿态残差试验在另外两片训练、整片留出，预测七步各二维残差。共同输入为相同的两点水平速度及速率。末帧臂还读同一33关节在各帧以这些关节几何中心居中的原生三维形状及有限性掩码（坐标系不做重新拟合）。首末臂再读取从 t0−6 至 t0 的居中形状变化除以实际帧号间隔/15；五帧臂保留原首末变化，再增加从 t0−5、−3、−2 至 t0 的三个变化除以各自时间差。每个变化块按这两帧共同有效关节居中并带其掩码。所有已入组窗恰有33个共有完整关节。四臂按固定嵌套特征块设计；增量包含额外实测中间形状及其对应模型自由度。未在任一简化臂填入伪造的中间姿态。

训练固定均方损失加 1.0 倍系数平方和、未惩罚截距。先在训练片内按所有训练窗统计各列均值、总体标准差，常数列转换为0。训练窗等权，无调参，也无跨片身份拼接。单次确定性 NumPy 岭回归，无神经模型、无外部基准阈值变动。主比较为五帧臂减首末臂的首选单路径 ADE，三片各等权，片内按窗等权。另列五帧减纯运动、末帧减纯运动、首末减末帧、四学习臂各减匀速的 ADE/FDE，并公布逐片结果。各片另先给每位片内行人等权，再对三个片等权。对两个加权量按片内行人有放回配对抽样20,000次，PCG64(2026)，抽到某个行人时保留其所有窗，再以各自的加权规则聚合，给条件95%百分位区间。第三片6窗均属同一人，该片内重采样不提供额外人物变异；不外推至新片或人群。

私有结果保留同窗身份摘要与原始历史帧号、全部折索引、输入特征、预测、误差及拟合关系。地面尺度为 ST 的发布坐标解释，未得原始人工3D中心独立定标；ST 未保留框的插值位，HST 为33点三维估计。此项不使用人工二维姿态或相机帧的纳秒时间戳，未测整3秒或冻结 PINNS 预测器跨域效能。本地只作真实输入检查和合成测试，真实拟合与前向只在 Kaggle CPU。
