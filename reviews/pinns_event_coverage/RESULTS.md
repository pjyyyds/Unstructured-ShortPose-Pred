基于此前研究的四个地点、47 片段与 1,482 窗。主分析比较既有 M0（运动）、M1（运动与显式质量门控姿态）；候选不重新排序。逐事件计数和完整逐地点结果见[聚合 JSON](event_coverage_scores.json)，独立复算见[核验 JSON](verified_provenance.json)。五类可以重叠，各项推断条件于现有地点、模型和片段。

真值起步、停止、左转、右转、保持依次有 49/20、53/15、214/33、208/22、975/47 窗/片，17 窗属多类。以下分子为 seed 42 合并原窗的实际数量，先列 M0，再列 M1。

* 起步的首选均为 0/49，至少一个候选命中均为 30/49，剩余 19 窗两模型均未覆盖。按四地点等权，任一候选的起步召回均为 82.4%。这个数与合并的 61.2% 有差异，因为美国为 8/27，意大利、日本和泰国分别为 8/8、12/12、2/2。两模型均在 71/1,433 个阴性窗中产生了起步候选。

* 左转首选为 38/214 和 42/214，任一命中为 128/214 和 132/214。阴性窗中任一误触为 398/1,268 和 411/1,268。

## 复现

将私有四个归档放在同一输入目录中，分别为 `pinns_matched_histories.npz`、`anchored_six_candidates.zip`、`reranked_modes.zip`、`shortpose_heldout_five_seeds.zip`。最后一包仅用于核对原 8 个 seed 42 权重的 SHA-256。两个程序只读取历史、已存预测与误差，所有计算均无需模型前向或训练。以项目根目录为工作目录运行下列命令。

```bash
PYTHONPATH=. python reviews/pinns_event_coverage/score_archive.py . INPUTS event_coverage_scores.json
PYTHONPATH=. python reviews/pinns_event_coverage/verify_scores.py . INPUTS event_coverage_scores.json verified_provenance.json
```

来源与 SHA-256 已随聚合结果保存。由 seed 42 两模型 17,784 条候选轨迹重算的首选和最低 ADE 模式，5,928 个索引与独立存档完全相符；首选和最低 ADE 候选的逐窗 ADE/FDE 最大误差为 1.38 微米以内。两组归档来自 Kaggle v373619572、v373583293。与先前公开的 seed 42、阈值 0.5 的逐地点事件 TP/FP/FN 共 120 项全部一致。
