# 冻结 PINNS 人车邻居图移至大连校园共享空间

本协议在构建 DUT 邻接图、运行任何本试验外部预测及查看外部评分前登记。DUT 同一校园机位提供 11 个片段。采用已冻结的 3,066 个非重叠五帧行人观测，879 个片内行人身份，窗键摘要为 02c44cf55e5ca8690dc1fe9ac9c076af44dc89f11629b8ccc9e725e49e4580ec。保留目标本人有完整未来的所有入组窗；邻居出现在观测末帧即有资格，不看其未来轨迹，也不要求有姿态。严禁跨片拼接人物、车辆或运动。数据集作者给出的逐帧跟踪人点和车辆中心作为建图输入，本项检验基于已提供的跟踪位置与身份的预测效用。它没有评估自动获取车辆位置的能力。

**建图与速度。** 只允许使用该人五个已冻结的实际历史帧号及对应时钟，选中者均不晚于 t0。每片坐标除以作者自己的像素/米比例；人为人点，车辆为车辆标注矩形的中心 x_c/y_c。身份为（片、Person/Car 类别、ID）。在最后一帧排除本人及中心距离≤1e−5米者，按距离选取10米内最近12个，正好相等时按来源类别名再按 ID 排序。每个邻居当前速度和图中目标本人速度均为当前与五个观测中最近一次有该身份的先前位置之差，除以两张实际视频的呈现时间差。源视频均为 1000/23976 秒/原生帧；保留最近原图取样后的交错间隔。相对速度为邻居减本人，径向接近速度为其与位置差的负点积除以距离加1e−6。速度缺失保留这条边，双速度分量与径向速度置0，无效位置0。九项为二维位差、二维速差、距离、径向速度、相对速度有效位、邻居和本人的历史存在比例；人有效速小于0.20 m/s 编码2，否则（含无速度）编码0，车编码6。11段的源轨迹、比例尺和历史引索均逐项校验。登记统计各片和总体的入池/保留人车数、12槽截断、速度缺失、四种邻体支持及覆盖。

**自身运动、姿态与方向。** 共同主干严格复用既有 DUT 个体实验的五点运动编码和类型，固定名义 0.1s 以保持 M1 输入一致；邻居图单独根据真实呈现时差产生米/秒。目标位置平移至末点，xy 轴为原图右/下，目标运动方向由自身二维历史位移和速度表出。原训练模型没有个人朝向角或身体向量字段，故这里不新增一个自拟朝向。对四个角度0、90、180、270度同时旋转地面自身轨迹、相对位移及速度，保持原图姿态、米数距离/径向速度及关联成员不变，将预测路径转回原 DUT 坐标后计分。只将0度作为主要评价。姿态从另一项已冻结的完整 DUT 检测姿态缓存读取（输入文件 dut_shared_space_pose_cache.zip），核对每个窗的五个真实帧、全部键、匹配类别与掩码；缺检的位置框、关节均归零，保留0/5至5/5的所有窗口。不得用试点11窗缓存代替完整3,066窗。

**固定权重与干预。** 仅使用先前已验收的 PINNS 人车图同机实验归档 pinns_graph_control.zip（SHA-256 0b3e590b8d7cb2bf99670fd27d3bdbf2a40fa0e77bf29f7ac0423b73535589f8）。四个源留地点各有同轮、同训练条件的 M1、真图训练 M2b、空图训练 M2b，各臂共四组冻结参数。每个源模型独立选择最高概率候选，按先对四组误差等权、再片内窗等权、最后各片等权聚合。真图训练模型另按同一权重关闭所有边／仅关闭车辆／仅关闭行人，不补选第13邻居。另报末两点按真实呈现时差延拓的匀速。所有模型、筛选、角度、阈值均不据 DUT 误差调整；单元在 Kaggle CPU 做冻结前向，不新拟合。

**终点与报告。** 主终点为原轴0度、11片等权的真图 M2b 减同训练实验 M1 首选 ADE（米）。次要为同窗 FDE、真图减训练空图、训练空图减 M1 及三个同权干预分别减原真图。按原时刻五帧后30个最近实际未来对应作者标注计分，保留实际末点呈现时间范围。0度主样本对上述配对差按整片有放回重采样11片共20,000次，NumPy PCG64(2026)，采用片均值的百分位95%区间。另报所有角度与逐片分数、按窗均值、空/仅人/仅车/混合图支持、姿态帧关联数。分组内仅给有该组的片等权并明确分母。四组源权重是同一套 PINNS 研究的对应训练重复条件；结果仅描述这一个外部摄像机的11个片段，不把源模型或片算作独立新地点。保存逐窗首选模式、概率和六条3秒预测路径、回转后的误差、配对分母与摘要，在读取/计算未来误差前完成全部角度的候选选择。分享仅限聚合；作者来源的视频和位置轨迹不随公开代码转载。
