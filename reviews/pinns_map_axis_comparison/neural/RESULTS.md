# PINNS 五帧神经因果地图两臂配对结果（M2a）

- **云端版本与独立核验**：Kaggle `w1-gpu1-pinns-neural-map`（`scriptVersionId=373962571`，Tesla T4，`pinns_neural_image_geometry_pair.zip` SHA-256 `698c6c28...`）。`verify_return.py` 独立比对原真值、修正因果地图掩码、权重摘要及 20,000 次整片重采样区间全部一致（见 `verified_return.json`）。
- **测试集全窗聚合指标（497 窗，其中 233 窗具固定 3.0 s 真值）**：
  - 修正因果轮廓坐标臂 `real_xy`：**`0.4913 m` ADE** / **`1.0516 m` 末有效步 FDE** / **`1.1925 m` 固定 3.0 s FDE**
  - 坐标置零仅保留可用标志臂 `zero_xy`：**`0.4885 m` ADE** / **`1.0619 m` 末有效步 FDE** / **`1.1966 m` 固定 3.0 s FDE**
- **主配对比较（`real_xy - zero_xy`）**：
  - 全测试集 ADE 差：**`+0.0029 m`**（95% 整片重采样区间 **`[-0.0169, +0.0307 m]`**，跨零）
  - 末有效步 FDE 差：**`-0.0103 m`**；固定 3.0 s FDE 差：**`-0.0041 m`**（意大利留出录像上 ADE 改善 `-0.0399 m`、固定 3.0 s FDE 改善 `-0.1333 m`）。
- **结论**：在单种子同分布划分下，将修正纵轴并严格因果截断的局部无语义轮廓折线接入 `M2a` 网络后，终点 FDE 略有下降，整体 ADE 差异接近零且置信区间跨零，按开题情形 C（无显著净增益亦无反转伪崩盘）记录。
