# 原几何岭回归的随访长度与配对终点误差

本复算读取 Kaggle 版本 373590565 已存的单轨迹预测和真值。它比较旧版 BEV 纵轴下的影像轮廓组和地图可用标志组，两组使用相同的历史运动和可用性标志。原始私有 ZIP 的 SHA-256 为 `093a4d1901fe392e9181897287b86cddf686bd46d1a063a706c733cf7ca58fda`。[原实验聚合](../../../results/pinns_causal_geometry.json) · [本次复算结果](aggregate.json)

497 个测试窗在第 1、2、3 秒分别有 497、397、233 个位置标签。233 窗完整覆盖 30 步（46.88%），其余 264 窗只在尾部缺测。没有窗口在缺测后恢复标注。四处地点的完整窗分别为美国 168/316（53.16%）、意大利 12/20（60.00%）、日本 49/150（32.67%）、泰国 4/11（36.36%）。掩码记录可评分时长，无法确定记录终止的原因。

误差单位为米，差值为影像轮廓组减可用标志组。原预设指标 ADE 覆盖每窗所有有效时步，497 窗的配对差为 +0.0232，95% 区间 [−0.0126, +0.0417]。同一预测的两种终点定义得到以下结果。

- **最后有效时刻。** 497 窗、21 片，每个窗口的终点介于 1.5 至 3.0 秒。轮廓组和可用标志组 FDE 分别为 1.3267、1.2708，配对差 +0.0559，95% 区间 [−0.0237, +0.0950]。
- **固定 3.0 秒。** 仅纳入第 30 步有标签的 233 窗、8 片。两组 FDE 分别为 1.4088、1.3144，配对差 +0.0944，95% 区间 [−0.0547, +0.1369]。

两项 FDE 的均值与配对差已在原归档报告，区间是此次补算的探索性结果。各指标按自身可评分窗口固定四个地点的占比，各地有放回抽取相同数目的完整片段，每次带入所抽片段内全部合格窗。以种子 2026 重复 20,000 次，取两侧 2.5% 和 97.5% 分位数。固定 3 秒时，美国有 5 个支持片段，意大利、日本、泰国各仅 1 个；后三地的片间变异无法估计。这里的区间仅反映所用开发场景内的片段重采样。
