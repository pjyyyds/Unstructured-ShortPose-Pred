# 按实际观测时长判定姿态质量

五、十、二十帧各使用同样 623 个预测时刻和三秒目标。按各次可用历史重算姿态质量，三档窗数分别为 188/283/152、177/294/152 和 167/325/131。五帧至十帧有 67 窗换档，五帧至二十帧有 114 窗换档。原文三种判定条件在五帧时让 35 窗缺少归属、65 窗同时归入两档。公开实现始终先判断清晰，再判断重低质，其余归中等。

二十帧重低质组中，五种子四地等权的 ADE 为纯运动 0.7543 m、显式姿态门控 0.7722 m、隐式姿态门控 0.8224 m。显式门控比隐式门控低 50.24 mm，按地点内整片抽样的 95% 区间为 −77.91 至 +2.15 mm；其相对纯运动臂高 17.90 mm，区间为 +0.17 至 +43.42 mm。九格和两个对照的结果均保留。各格样本来自同一批录像，区间以已拟合的五个种子和固定四地为条件。

将已有的四个额外种子 ZIP、种子 42 的五份原始归档及匹配窗清单保存在同一输入目录。具体文件名见[原有五种子复现说明](../pinns_matched_multiseed/REPLAY.md)。在仓库根目录运行下列命令。两者从已保存的轨迹、误差和观测作统计汇总。

```sh
python reviews/pinns_observation_quality/analyze.py INPUTS scores.json
python reviews/pinns_observation_quality/verify.py INPUTS . verified.json --compare scores.json
```
