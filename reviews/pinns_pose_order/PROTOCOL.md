# Five-frame PINNS pose-order intervention

**Registered before outcomes for these perturbations.** Prior information includes the four sites' five-seed M0/M1 performance and a single-seed audit that removed all joints or reversed all five entire feature frames. That reversal also moved the terminal pose, masks, confidence, scale, and pose–motion alignment. This protocol has one primary order contrast. It does not reuse the previous reversal as a replicate.

The target is the predicted top-probability trajectory under the already fitted five-frame M1. The 20 weights comprise one M1 fit for each of the four PINNS held-out sites and the five seeds 42, 1024, 2025, 3407, 4096. Each fit used the other three sites for training and excluded all clips from its held-out site. Each fit is evaluated only on its respective held-out site. Previous development on these four sites limits generalization to a new site. No fine-tuning, candidate reranking, subgroup selection by errors, or repeated model selection enters this audit.

All 1,482 registered windows have the same five past observations and 30 future labels at 10 Hz. The 47 clips give 816 US, 84 Italian, 432 Japanese and 150 Thai windows. For each forward pass the model receives only motion history, pedestrian type, observed pose, and observed aggregate quality. Source identities, weights, and window order are checked before use. The scorer opens future coordinates for a batch after the four forecasts are set. The model retains the original highest-probability mode, breaking ties by the lowest index, in each condition.

1. **Recorded.** All model inputs are unchanged. Each recorded ADE/FDE must reproduce the corresponding archived window and weight under the original CPU replay tolerance.
2. **Interior order (primary).** Exchange normalized XY geometry at the second and fourth of the five observed slots for each joint valid at both slots under the same hip-root/box-root convention. Retain the first, third and terminal poses. Leave all confidence, masks, root indicators, box scales, quality vectors, ground motion, and their timestamps byte-for-byte intact. The exchange conserves each eligible joint's two original positions and its unweighted coordinate mean. It changes which geometry accompanies the other cues at those two instants. Where only some joints qualify, the altered skeleton can mix recordings from two observed moments.
3. **Static geometry (descriptive).** For each joint and root convention, replace its valid normalized XY coordinates by the latest valid coordinates from that joint under that convention within the same five observations. Missing observations remain missing, and the latest frame remains identical. The method keeps static shape and per-time quality, including separate templates when the root convention switches. It can mix joint measurements from different valid historical frames. All source observations are available by the prediction trigger.
4. **Disabled pose residual (descriptive).** Keep the complete observed input, encode it, and bypass the M1 pose residual at its fusion layer using its existing no-pose branch. The resulting representation is LayerNorm of M1's own motion representation, with gate zero. These weights were trained with pose. Independent M0 training addresses a different comparison.

**Manipulation coverage, counted before scoring.** The order exchange changes numerical XY in 1,324/1,482 windows (89.34%) and 21,141/25,194 window–joint pairs (83.91%), covering 42,282/125,970 joint-time slots. The static condition changes 1,478/1,482 windows and 24,005/25,194 window–joint pairs. Retain every window in the primary denominator, including unchanged ones. Input-side counts and fractions by site are fixed in the companion JSON. A prespecified descriptive subgroup is the 449 windows whose first input equals that person's first sampled annotation in the clip (240/28/117/64 by the sites above). Its order exchange changes 392/449 windows and 6,196/7,633 window–joint pairs. This label describes annotation timing and supplies no physical visibility information.

**Primary endpoint.** The primary number is interior-order ADE minus recorded ADE in metres. Each site's windows are averaged first, then the four sites and five seeds receive equal weight. Estimate the conditional, two-sided 95% percentile interval from 20,000 whole-clip resamples within site, RNG seed 2026. Average seed effects within each identical window before resampling, use the same sampled clips for all paired methods and ADE/FDE, and weight the four sites equally on every draw. The primary decision uses only the all-window ADE contrast. FDE (distance at step 30), static and disabled controls, per-site/seed displays and the first-annotation subgroup are descriptive. These intervals do not account for development on these sites, future training, or resampling sites from a larger population.

**Interpretation.** A path shift, nonzero gate change, or top-mode change establishes sensitivity. Lower recorded ADE with a primary interval above zero supports a predictive contribution of the recorded interior geometry assignment compared with this one perturbed assignment for these fixed fits. Even an interval wholly above zero can represent a very small effect, so report values in metres. A lower recorded error than static alone cannot distinguish useful order from variation, posture diversity, coordinate–motion alignment, or noise. A lower recorded error than disabled alone supports the use of some pose information. An interval crossing zero leaves the sign of the primary benefit unresolved. An interval wholly below zero favors the perturbed geometry. Unchanged output is weak evidence about sensitivity to other possible timing manipulations. No combination here establishes a causal physiological precursor, a pose advantage over a separately trained model, or efficacy on new locations. No error threshold for deployment has been prespecified.

**Runtime and output.** Only the accepted five-seed archive (42,019,120 bytes, SHA-256 `0bf2745ab2d5ddcf5f5fbb5d330e6c6cc800625cec301f4c7105d031bdb49d2d`) and official PINNS labels/calibrations plus inventory are required. The archive contains pose.npz and all 40 neural checkpoints; 20 M1 checkpoints are used. No video decoding, ONNX, GPU or training is required. The scoring workload is 125 original-size batches per condition or 500 CPU forwards altogether, covering 29,640 single-window predictions. The private compressed float64 data has shape (5 seeds, 1,482 windows, 4 conditions, 5 fields), with ADE, FDE, mean distance from recorded top path, binary top-mode change and absolute gate change as fields. It includes window identities, the 449-window flag and axis names for independent reconstruction. The aggregate JSON contains per-seed/site means, macro results and paired differences. Publish aggregates only.
