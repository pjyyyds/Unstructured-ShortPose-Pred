# PINNS 修正鸟瞰地图后 12 人同刻实景 Tesla T4 前向耗时结果

- **云端版本与独立核验**：Kaggle `w2-gpu-sync-latency`（`scriptVersionId=373989788`，硬件实测 `Tesla T4` CUDA 13.0 / PyTorch `2.11.0+cu130`，返包 `pinns_sync_latency_source_label_results.zip` SHA-256 `b5a65fbbd3c18029ca8779d946c7efc8bf5b9d6d54277b0d3671622b89ff49ad`）。本地逐项比对 `SOURCE_LOCK.json` 中的脚本、协议、冻结权重（`PINNS_T5_Ours_Full_seed42.pt`，471,442 参数）与三档修正地图输入指纹，并从全部 72 格（2 实景时刻 × 3 历史时长 × $N=1\ldots 12$）各 100 次原始计时序列独立复算均值、中位数与 P95，误差 $< 10^{-9}\text{ ms}$（见 `verified_timing_summary.json`）。
- **美、日两处 12 人同刻实景等权前向耗时（FP32，TF32 关闭，每格预热 25 次 + 同步测量 100 次）**：
  - **$T=5,\ N=1$**：主机同步墙钟均值 **`12.295 ms`**（中位数 `12.104 ms`，P95 `13.579 ms`；CUDA Event 均值 `12.171 ms`）
  - **$T=5,\ N=12$**：主机同步墙钟均值 **`14.762 ms`**（中位数 `14.742 ms`，P95 `15.963 ms`；美国 `14.500 ms`、日本 `15.025 ms`；CUDA Event 均值 `14.351 ms`）
  - **$T=10,\ N=12$**：主机同步墙钟均值 **`13.998 ms`**（中位数 `13.883 ms`，P95 `14.996 ms`；CUDA Event 均值 `13.883 ms`）
  - **$T=20,\ N=12$**：主机同步墙钟均值 **`15.063 ms`**（中位数 `14.932 ms`，P95 `16.194 ms`；美国 `14.963 ms`、日本 `15.164 ms`；CUDA Event 均值 `15.070 ms`）
- **结论**：在包含真实 100/124 条五帧行人邻边与修正正向鸟瞰局部轮廓折线的 12 人满载实景下，`Ours_Full` 在单张 Tesla T4 上的同步前向耗时均值与 P95 均稳定在 **`14.0–16.2 ms`**，较 `25 ms` 预测网络实时参考线留有 **`35.2%–44.0%`** 裕度（范围限于已在显存的特征前向，不含视频解码与姿态检测）。
